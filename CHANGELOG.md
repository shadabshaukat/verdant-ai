# Changelog

Changes on `main` are listed here before a versioned release is tagged.

## Unreleased

- Multi-cluster PostgreSQL onboarding, generated least-privilege setup SQL, capability-aware deep SQL monitoring, fleet metrics and per-cluster dashboards.
- GUI chat profiles for Ollama, OpenAI-compatible APIs, Amazon Bedrock and OCI Generative AI, with native-tool connection tests.
- Encrypted saved credentials, authenticated access roles, console mutation audits and a separate production deployment mode.
- Bounded fleet investigations with durable model/tool provenance, scoped retrieval and optional allowlisted statistics maintenance.

- Cross-platform Node launcher and `.env` configuration for Docker Compose.
- Bundled Ollama deployment and configurable external model endpoint.
- Checksummed, serialized control-schema migrations with upgrade history.
- Typed runtime configuration, independent worker heartbeat and graceful shutdown.
- Consolidated console styling and improved keyboard/mobile interaction.
- Contributor documentation, portability CI and Apache 2.0 licensing.

The existing monitoring, bounded remediation, review memory and hybrid PostgreSQL retrieval remain part of the platform. See [VALIDATION.md](docs/VALIDATION.md) for measured behavior and limits.
